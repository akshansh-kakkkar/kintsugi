# Kintsugi 
 金継ぎ - break it. fix it. ship it.

## Description
Its a website made for ysws which is still in draft named as `kintsugi`. Kintsugi is Japanese art of reparing broken pottery by mending the cracks. I made Kintsugi because I wanted to contribute to some ysws in hackclub and I always wanted to make a ysws style website with good animations and stuff but never got a chance to make one.

## How Kintsugi works
- User creates a project
- connect hackatime
- fill the all information which is required
- ships the project
- waits for the review
- reviewer reviews the project(reviewer panel is being made by the other person in the team)

## Features
- Create Project
- Read Project
- Update Project
- Delete Project
- Ship Project
- Edit Project
- Time Tracking using hackatime

Along with me one more person worked in the team we divided our work I mainly focused on frontend part and he mainly focused on the backend part. It was a bit challenging for me to work on a big team project becuase I have never worked on any ysws website but while working this I learned alot specially I have a habit of writing a backend in server instead of actions file which made me learn actions too well along with that I learned to use drizzle because I usually prefer to use prisma.



## Installation
Prerequisites 
- You need to create a project in Neon for the database URL.
- have a hackclub account for connecting hackclub auth.
- have a hackatime account for connect hackatime.
- Connect your better auth with Neon.
- Get a Hackclub CDN.
- Get a Slackbot Token.

1. Clone the Repository
```
git clone https://github.com/akshansh-kakkkar/kintsugi.git
```

2. Install the dependencies
```
bun install
```

3. Add the Env

```

DATABASE_URL=

HACKCLUB_CLIENT_ID =

HACKCLUB_CLIENT_SECRET = 

BETTER_AUTH_SECRET = 

BETTER_AUTH_URL = 

HACKATIME_CLIENT_ID =

HACKATIME_CLIENT_SECRET = 

HACKATIME_REDIRECT_URI = 

SLACK_BOT_TOKEN=

CDN_KEY=

```


4. Run the server

```
bun run dev
```
